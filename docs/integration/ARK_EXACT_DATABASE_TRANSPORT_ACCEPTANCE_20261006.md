# Exact archive database transport acceptance

The existing bounded SQL import procedure is now a reusable administrative adapter for the source-bound resumable coordinator. `scripts/import_chatgpt/exactArchiveSql.ts` generates a transaction-local DO block. It validates target UUIDs and strict bounded message payloads, checks project ownership under a share lock, takes an owner/project advisory transaction lock, locks matching archive rows, rejects mismatches before insertion, inserts with ON CONFLICT DO NOTHING, and verifies exact fields before successful transaction return. Any failure aborts the block. Exact repeats do not update content, timestamps or embeddings. Both deployed global message and thread/message uniqueness contracts remain respected.

Historical content is encoded in collision-free nested dollar-quoted JSON literals; source text cannot close either SQL delimiter. No new table, migration, public RPC, engine, worker, model call or credential is introduced. The caller binds the intended database explicitly; payload ownership checks do not make arbitrary database execution a public capability. Advisory locks protect participating importers; this does not establish full-archive snapshot isolation or safety of unrelated existing writers.
