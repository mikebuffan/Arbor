# Acknowledgment continuation contract — 2026-10-06

When an unfinished durable agency objective exists, a bare acknowledgment is continuation permission, not a new objective and not a completion signal.

Covered acknowledgments: okay, ok, k, yes, yep, yeah, go, alright, all right, go ahead, continue, keep going, do it, finish it.

Rules:
- preserve the existing goal and unresolved work;
- preserve ARK objective/action ownership and idempotency identity;
- do not convert acknowledgment text into a replacement goal;
- do not mark the objective complete because the user acknowledged progress;
- continue safe/reversible/authorized in-scope work without asking for another "go";
- return control only for verified parent-goal completion or a genuine protected/human boundary;
- after restart, durable unfinished state has the same interpretation.

An explicit task switch still wins. Examples: "new task", "instead", "drop that", "stop this", "switch to ...".
