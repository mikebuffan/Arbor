## Rollback / failure
- Keep owner feature flags OFF or return them OFF on unexpected behavior; stop the independent LM path before troubleshooting sensitive content.
- Revoke the relevant individual Grove project grant or owner invitation for access withdrawal **only after** reviewing transcript cascade/deletion expectations; do not delete unrelated Firefly or research records.
- Disable the isolated Grove Vercel deployment or restore its prior approved code; **never** disable/overwrite Firefly production as a Grove rollback.
- A failed test, limited history window, unverifiable retry persistence, no real GPU, unavailable ARK read, or unprovisioned owner is HOLD, not success. No background processing is implied by this checklist.
