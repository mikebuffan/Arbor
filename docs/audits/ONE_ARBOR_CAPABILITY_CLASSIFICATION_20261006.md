## Evidence labels

| Label | Meaning |
|---|---|
| MODEL_NATIVE | Capability supplied primarily by the current foundation model/tool environment |
| ARBOR_ARCHITECTURE | Capability is explicitly represented/owned by Arbor source/state architecture |
| SOURCE_PROVEN | Implementation exists and focused source tests pass |
| BENCH_PROVEN | Integrated exact-head acceptance passes under synthetic/disposable/local conditions |
| PREVIEW_PROVEN | A bounded behavior has been demonstrated against an owned Preview/live-like environment |
| LIVE_PROVEN | Current candidate has been deployed and demonstrated end-to-end in its intended live environment |
| MODEL_INDEPENDENT | Behavior has survived controlled replacement of the underlying reasoning model within defined tolerances |
| HYPOTHESIS | Plausible capability not yet demonstrated to the next evidence tier |

## Promotion rule

No capability advances merely because:
- its source exists,
- a model says it can do it,
- a focused test passes,
- a similar older build once worked,
- or the behavior seems plausible in conversation.

Promotion requires evidence appropriate to the next tier, preserved with exact source/head/run provenance.
